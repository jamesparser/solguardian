# SolGuardian

**Automated exploit hunting for Solidity & Solana**  
IBM Bob 2.0 Hackathon · Jason Parser Research

> Point SolGuardian at contract source. Parallel agents hunt real exploit classes and emit ranked findings with PoC stubs and patch sketches.

Built and demonstrated **in IBM Bob IDE** (Agent mode + subagents). Portable CLI core for use after the event.
